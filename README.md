# Software & License Tracker

A simple SQLite database for keeping track of software you own or subscribe to. Record program names, versions, license types, renewal dates, and notes.

## Features

- Add and update software records
- View your software list
- Find subscriptions renewing in the next 30 days
- Store data in a local SQLite database

## Requirements

- SQLite 3

## Getting started

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Start SQLite and create a database:

   ```bash
   sqlite3 software.db# Software-License-Tracker
